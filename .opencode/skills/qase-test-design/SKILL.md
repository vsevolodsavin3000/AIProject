## Алгоритм работы
1. Примени техники тест-дизайна: эквивалентное разделение (EP) и анализ граничных значений (BVA).
2. Обязательно покрой:
   - Основной позитивный сценарий (Happy Path).
   - Негативные сценарии (невалидные данные, отсутствие прав).
   - Граничные значения (минимальная/максимальная длина, пустые поля).
3. В заголовке каждого кейса укажи связанный ключ задачи Jira, например: `[PROJ-101] Успешная авторизация по валидному токену`.
4. Вызови `create_test_case` для каждого кейса, заполнив `preconditions` и пошаговый массив `steps`.
